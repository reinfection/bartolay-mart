# Bartolay Mart - Inventory & User Management System

A web-based inventory management system built with PHP, MySQL, and vanilla CSS.

## Features
- **Dashboard**: Live summary metrics (Total Products, Total Value in ₱, System Users, Pending Approvals).
- **Product Management**: Add, edit, and delete products with custom modal confirmations.
- **User Management**: Role-based access control (`root`, `manager`, `staff`) with deletion protection.
- **Registration Approvals**: Admin workflow to approve or reject pending accounts with role assignment.
- **Unified Custom Modals**: Uniform HTML/CSS overlay dialogues across all actions.

## Tech Stack
- PHP (MySQLi)
- MySQL / MariaDB
- HTML5, CSS3, Lucide Icons
- XAMPP (Apache)
